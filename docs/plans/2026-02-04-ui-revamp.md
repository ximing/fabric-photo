# 开发计划：编辑器 UI 产品化重构

日期：2026-02-04

对应技术方案：`docs/design/2026-02-04-ui-revamp.md`

## 目标

把编辑器 UI 重构为明暗双主题的专业工具风：主题 token、浮动工具选项条、缩放胶囊、导出弹层 segmented 化。只改 `packages/react`（及 demo 对主题变量的消费），core 零改动。

## 约束

- `packages/react` 只 import `@gmi/fp-core` 公开 API；组件零编辑逻辑
- 样式写在 `styles.css` 的 `@layer components`，`fp-` 前缀；组件不含内联样式
- 测试与源文件同目录；jsdom
- 每个任务结束后 `pnpm typecheck` 与 `@gmi/fp-react` 测试需通过

## 验收

- 暗 / 亮主题可切换并写入 localStorage
- normal / text / pan 无空白选项行；绘图 / 裁剪模式浮动条出现
- 导出选项不减少，交互为 segmented
- `pnpm typecheck && pnpm test && pnpm build && pnpm build:demo` 全绿
