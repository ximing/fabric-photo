# 开发计划：Vite + tsup 现代化改造

日期：2025-10-24

对应技术方案：`docs/design/2025-10-24-vite-tsup.md`

## 目标

库构建从 rollup 迁到 tsup，demo 从 webpack 迁到 Vite（本地开发与 GitHub Pages 同源），并现代化 GitHub Actions。

## 约束

- 包管理器 pnpm；Node 20
- fabric.js 锁定 1.7.3，bundle 进库产物
- `src/` TypeScript strict；改动后 `pnpm typecheck` 必须通过
- 不升级 React 16、不改 `src/` 库逻辑、不动 `scripts/ralph/`
- demo 端口 `9876`；Pages 路径保持 `/fabric-photo/`
