# 技术方案：编辑器 UI 产品化重构（明暗双主题）

日期：2026-02-04

## 背景与问题

编辑器功能已经齐，但界面组织不够产品化：

1. 工具选项条固定占 grid 一整行，normal / text / pan 模式下完全空白
2. 导出是 4 行 radio 表单 + 确认按钮，二次确认结构过于突出
3. 工具栏带文字标签偏宽；顶栏塞了缩放控件；只有一套浅色样式

## 目标

- 专业工具风视觉，明暗两套主题
- 消除空白第二排：工具选项改为画布顶部浮动条，按需出现
- 导出弹层收敛为 segmented 控件，选项不减少
- 全程不触碰 core：纯 `packages/react` + demo 的 UI 层改造

## 非目标

- 不新增编辑功能；不改 core 任何 API
- 不做响应式 / 移动端适配
- 不做「一键下载 + 格式菜单」——保留全部导出选项的紧凑弹层

## 设计

### 1. 主题系统

在 `packages/react/src/styles.css` 定义语义化 CSS 变量，暗 / 亮两套值（`--fp-bg-app` / `--fp-bg-panel` / `--fp-bg-elevated` / `--fp-border` / `--fp-text` / `--fp-text-dim` / `--fp-accent` / `--fp-shadow-pop`）。

- 默认跟随 `prefers-color-scheme`；根元素 `data-theme="dark" | "light"` 时覆盖
- TopBar 日 / 月按钮，选择持久化到 `localStorage("fp-theme")`
- 现有硬编码色值全部迁到变量

### 2. 布局

- grid 由三行改为两行：顶栏 +（工具栏 | 画布 | 右侧栏）
- `ToolOptionBar` 重构为 `FloatingOptions`：绝对定位浮于画布顶部居中；仅 crop / freedraw / line / arrow / shape / mosaic 渲染，其余返回 null
- 缩放控件迁到画布底部居中浮动胶囊
- TopBar 精简为：图名 · 撤销/重做 · 主题切换 · 导出
- Toolbar 收窄为纯图标 rail，工具名进 tooltip

### 3. 导出弹层

选项全保留（格式 / 质量 / 倍率 / 范围）。radio 替换为 segmented（`role="radiogroup"`）。开合逻辑、文件名拼接、`toDataURL` 参数组装不变。

### 4. 组件变化

- 公开导出 `FloatingOptions` 替代 `ToolOptionBar`（自定义 children 的接入方需换组件；缺省布局的 demo 不受影响）
- `TopBar` 去掉 zoom 三件套，加主题切换
- `packages/react/README.md` 组件清单同步更新

## 验收门槛

- `pnpm typecheck && pnpm test && pnpm build` 全绿
- demo 上暗 / 亮两主题、浮动条按需出现、导出弹层 segmented 可操作
